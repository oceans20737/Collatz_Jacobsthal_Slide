## **Overview**

This project provides a suite of calculation and automated verification tools for the **Shiftless Model**, which redefines the “$3n+1$” operation and the “unknown number of divisions by 2 (shifts)” in the Collatz mapping as the **adjacent sum (interference) of J-waves** and the **superposition of the basic wave (slide)** in Jacobsthal (J) space.

In the conventional Collatz conjecture, the greatest difficulty lies in the fact that **it is impossible to predict in advance how many times a number will be divided by 2** after performing $3n+1$ on an odd number $n$.

In this model, taking the adjacent sum of the J-spinor wave of an odd kernel extracts a **pure shift stream ($2^k$)** that forms the foundation of the next odd kernel. By superimposing the **basic wave (Least Significant Jacobsthal: LSJ)** corresponding to the hierarchy onto this stream, the model realizes the **J Slide**, where the trajectory advances without any arithmetic division.

As a result, the Collatz trajectory can be interpreted geometrically as **Wave Switching**, forming a **Shiftless Orbit** that completely eliminates the uncertainty of shifts.

## **Files**

A Python script that simulates the **Shiftless Orbit (J Slide)** from any initial odd value.

## **Usage**

Run the following command in a Python 3.x environment:

```
python code_01_collatz_j2_slide.py
```

When prompted, enter any positive odd number (e.g., 7, 11, 17).

The script will automatically compute:
- **J2 Expansion** (J-wave expansion of the odd kernel)  
- **Marge** (Extraction of the shift stream via adjacent sum)  
- **J2 Slide** (Generation of the next kernel via basic wave superposition)  

It also verifies whether the J2 Slide wave generated at each step **matches the analytical J2 spinor expansion**.

---

## **Verification**

The script checks whether the calculated J2 Slide wave matches the **true J2 spinor expansion of the next odd kernel**, based on mathematical identities.

Example:

```
--- Verification Result ---
[SUCCESS] All J2 Slides match analytical J2 waves.
```

If all steps match (SUCCESS), it demonstrates that the Collatz trajectory is a **pure Wave Switching phenomenon completely free of arithmetic division**.
